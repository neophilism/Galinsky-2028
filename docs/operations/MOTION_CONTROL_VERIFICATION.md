# G28-10 hero motion controls

The canvas flag has an accessible pause/resume control, persisted local preference, disabled device-reduced-motion behavior, stable static SVG fallback without JavaScript, portrait-animation suspension and hidden-tab/offscreen CPU suspension. Three-browser tests cover pause, persistence, resume, reduced motion, and no-JS still. No external media is requested by the control. More performance measurement and owner visual-reference confirmation remain open; a merged PR accepts these changes without falsely completing the entire G28-10 work package.
