# Safe, accessible Kirk–Evers HTML publication files

The Kirk–Evers issue page can link to separately reviewed local PDF, text and accessible HTML publications. For readable HTML from an approved Markdown draft, use the separate, **nonpublishing** generator:

```sh
npm run policy:html -- --source /path/to/reviewed-kirk-evers-bill.md --title "Kirk–Evers Free Speech and Democracy Protection Act" --filename kirk-evers-bill-v1.html
```

That is a **dry run**: it validates the source and prints the expected SHA-256 digest but does not save a file.

Add `--write` to create the exact versioned file under `apps/web/public/documents/`. Existing files cannot be overwritten by this tool. The source must be valid UTF-8 Markdown/text, below 200 KB. The document is static, without JavaScript, network assets, forms, iframes or active HTML; untrusted tags are escaped. The generated document includes a navigation index, landmark, headings, linked references, tables, accessible focus, print layout, and a restrictive CSP.

**Important:** Creating the file is not publication. It does not touch the campaign issue manifest, approve a legal draft, or deploy anything. Independently review the generated bytes and proposed policy before inserting a `status: "published"` record with correct reviewer, revision and SHA-256 into `content/public/site.json`. See `docs/operations/KIRK_EVERS_DOCUMENT_PUBLICATION.md` for that separate gate. No bill text has been supplied or fabricated by this tool.

HTML from sources other than this vetted generator must not be linked as approved publication documents. Legal and accessibility signoff, cross-browser preview of the rendered asset, and confirmation that the link represents a **proposal, not enacted law**, remain required.
