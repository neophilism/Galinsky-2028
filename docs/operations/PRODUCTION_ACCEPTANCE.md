# Production acceptance checklist

- Approved eight-view design reproduced, plus large top video on all three issue pages.
- Exact current public content and all required links/files/media verified; no accidental extra launch issues.
- Verification mail and authentication work on production origins; library access is immediate after verification.
- Twelve roles and twelve worksheet tools mapped; current materials, training, tasks, teams/events and admin operations work.
- Restricted activities show actual module/tool state and enforce current authorization; no hidden bypass.
- Protected reports/profile fields remain protected through every persistence, notification, search and export path.
- Real processor onboarding/rules/treasury signoff recorded; payment success is provider-confirmed; recurring cancellation and reporting work.
- Every supplied donation rule/committee/tax sentence remains readable at the point of giving.
- Accessibility, visual/browser, performance/load and security gates have evidence.
- Backup restored successfully; worker retries/replays are proven; alert and reconciliation owners exist.
- Production DNS/TLS/sender secrets/resources and costs are approved; test data and preview flags removed appropriately.
- Engine Room reports actual planned/implemented/merged/deployed/live-verified states and fresh data without PII.
- Live financial test is separately authorized and reconciled; no card is charged by assumption.
- README/AGENTS/plan/register/evidence/runbooks support a fresh-agent and nontechnical-operator handoff.

Record build SHA, content release ID, configuration digest, environment, date, tester/reviewer and result for each item. An unchecked external gate is a blocker, not an undocumented exception.
